# A060957 Lean 认证 R02

Lean 4.36.0，Mathlib v4.36.0，传递依赖锁定在 lake-manifest.json。

完整定理 A060957.Case130203.counterexample130203 验证 n=130203、p=53 的两个端点和中间不可达性。A060957.Case130203.disproof_source 否定原猜想的量词命题。公共乘积 C 由带证明的 opaque 定义给出，C_eq 明确它等于正权重元素的有限乘积。可执行的 p-adic 估值通过 Mathlib 的素因数分解恒等式证明与数学定义一致。完整扫描通过 decide +kernel 检查。日志内含原始公理输出和白名单审核。

另一个完整定理 A060957.Case954316.counterexample954316 同样验证 n=954316、p=101，两端点和对任意子集的排除均通过。大扫描拆成 16 个 Lean 模块以控制内存。

另外认证通用极值强制、有限子集判定完备性、固定数量的整数链子集和的双向区间刻画 chain_subset_sum_iff、任意有限列整数闭区间的 Minkowski 和 intervalSum_iff，以及抽象集合的空洞递推 gap_step_exact 和 smooth_step。抽象递推不含将图构造实现为实际子集乘积纤维的证明。Smoke.lean 单独检查 n=954316 和 n=130203 的两份约化列表。

## 复现

在已安装 Elan 的终端进入目录。首次运行 lake exe cache get 安装锁定的依赖和缓存。随后运行 bash verify.sh 依次验证两个反例，也可以把 130203 或 954316 作为参数只验证一例。脚本编译实际源码、将警告视为错误，并审计最终反例定理及原猜想否定的传递公理。实际输出位于 logs/。此处的完整形式化不主张 130203 是最小反例。

双三正则图、圆盘实现、固定 p 的渐近下界、二次切片连续性和单三次链底连续性还未在此工程中得到完整 Lean 认证。

证明源码和实际日志的摘要见 SHA256SUMS。disproof_source 一类结论使用工程内逐定义写出的原命题镜像。它可独立于在线题库编译。
